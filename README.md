Project Title: SunsonSolar Registration (Team3)
 
Description: A Web-based registration system that saves the users personal information and save it into database
 
Installation: 
Install Xampp version 8.2 or higher
download or clone this repository
put this project inside the Xampp/htdocs/folder
open the xampp and start Apache and MySQL
import the file sql into phpMyAdmin
rename the env to .env
put the database connection into .env
open the terminal in project
run the codeigniter (LocalHost:8080/main)
 
Usage:
Open registration page
Enter Required Inputs
select departments
check the terms and conditions
Click Sign up
The user informations will be stored in the database table
